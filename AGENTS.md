## CodeGraph

This project is intended to use the CodeGraph MCP server (`codegraph_*` tools) for structural code questions.

Use CodeGraph for symbol, dependency, caller/callee, impact, and architecture questions. Use native search only for literal text queries or after a specific file is already known.

If `.codegraph/` does not exist, ask whether to run `codegraph init -i` before doing structural analysis.

## Project Direction

Build toward the Phase 1 MVP first: 60-second AI talking-head short video generation from product information, script text, and an avatar image.

Avoid broad rewrites and speculative modules until the MVP contracts are stable.
