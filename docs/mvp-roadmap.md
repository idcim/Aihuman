# MVP Roadmap

## Milestone 1: Runnable Skeleton

- Backend task API
- AI script service contract
- Video render plan contract
- Docker Compose local environment

## Milestone 2: Persistence and Queue

- PostgreSQL task tables and migrations
- Redis Stream producer/consumer
- Task status transitions: queued, running, succeeded, failed
- Structured logs with request and task IDs

## Milestone 3: Real Media Generation

- Text-to-speech integration
- Subtitle generation
- FFmpeg render execution
- MinIO asset and output storage

## Milestone 4: Digital Human MVP

- 2D avatar talking-head generation
- GPU worker retry policy
- Model configuration and health checks
- Basic quality checks before marking a task succeeded
